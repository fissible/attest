## Decisions / blockers worth remembering

- **Bundle format `fissible.attest.bundle/v1` and CLI JSON schemas (`attest.cli.result.v1`, `attest.cli.export.v1`, `attest.cli.anchor.v1`, `attest.cli.upgrade.v1`) are pinned within v0.4.x.** Field names won't change without a format-version bump.
- **`release.sh` does NOT handle `-alpha` version suffixes** — its bump calculator parses `0.x.y` as integer-dotted-integer. For continued alpha releases, use the manual tag procedure documented in the fissible/.github README. To unblock release.sh, drop the `-alpha` suffix in VERSION first.
- **PSR-18 client is NOT shipped by default.** `OpenTimestampsCalendarClient::__construct` requires PSR-18 + PSR-17. `::withGuzzle()` is an opt-in static factory. CLI tests use injected mocks; production wiring uses `withGuzzle()` if Guzzle is installed.
