## Decisions / caveats to keep

- Bundle format `fissible.attest.bundle/v1` and CLI JSON schemas remain pinned within the `v0.4.x` line. Future field additions should be additive or require a format-version bump.
- PSR-18/PSR-17 clients are still optional. Core does not require Guzzle at runtime; `OpenTimestampsCalendarClient::withGuzzle()` is the opt-in factory.
- Claimed keys in bundles are informational only and are never trusted automatically by either core CLI or Laravel commands.
